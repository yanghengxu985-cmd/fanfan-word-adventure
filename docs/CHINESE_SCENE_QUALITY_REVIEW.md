# 语文全册场景质量审查与验收

审查基线：2026-10-04，26课现有阅读材料、23课共用组件、27个 Precision 工具。本文是本轮质量修复的验收要求，不是完成证明。

## 结论与范围

撤回此前“全册精修完成”这一笼统结论。此前入口、标题、按钮、溢出、教师存储隔离等检查，只能证明功能可用；它们没有证明每个状态的画面准确、过程完整、视觉风格连续。本轮只有代码语义、实际视觉和教材来源分别留下证据的课，才能标记对应项目已通过。本文不改写原发布台账。

26课的数据各有4个阅读阶段，共104个内容锚点。古诗两课的实际阅读入口按6首诗、每首4句选择，须另外覆盖24个诗句状态，不能拿4个概述阶段冒充全部诗句检查。第8、14、15课保留已认可的独立教学交互，以其实际故事停点、捕鱼时间轴、时间/花朵状态作为浏览检查入口，不强行改成四张幻灯片。

下面列出的对象来自现有项目材料及用户提供的目录，用于审查当前实现是否兑现自身教学说明；不意味着已经逐字核验2026纸本正文、课后题、背默范围或字词清单。

## 全局通过标准

1. 首图和后续图必须维持可接受的细节、构图和教学风格连续性。可以用精细插画、分镜、标注图或有明确目的的示意图；SVG本身不是缺陷，但用同一个几何场景换标题，不算内容完成。
2. 同一角色保持可辨识的外观；同一地点保留空间锚点；同一物件保留身份。不同物件、不同参与者和不同过程不得因共享 `artStep` 而被画成同一状态。
3. 关键动词必须有可观察的姿态、方向、接触关系或先后分镜。不要求每题动画，但不能仅给动作之后的结果。例如“持石击瓮”必须看得到持石/击打，“水迸获救”另有结果状态。
4. 热点可保留合理的同图近看：标记落在真实对象上，放大窗口仍包含目标，不裁成空地或无关树叶。图片整体缩放可称“取景放大”，不得靠文案把它包装成未发生的对象变化。
5. 合理的文字排序、关联、预测交互保留；关联选择至少呈现当前卡的对象。错误连线不应改写故事事实或把文学想象当作自然事实。
6. 声音工具的画面应出现当前声源。静音与强弱应有可读差别；合成音、波纹、光束须明确是示意，不冒充原声或教材原句。
7. 古诗允许保持同一完整场景，并用合理的局部取景/强调指向诗句；不要求每句换一张无关图片。若目标是光照路径、晴雨、视角或实际动作，变化必须发生在对应对象上。
8. 教师模式不读写个人学习记录。选择场景、热点或答案不记为掌握；纸笔检查必须由独立书写后的人为核对提供证据。
9. 1024×700、768×1024与1280×800下，标题、当前画面、主要切换/返回按钮可见；焦点不被标签、卡片或弹层遮住。首张图可读不代表所有状态满足布局。

## 27个共用 Precision 工具：逐选项验收

每个选项的语义ID均应传到场景层，或映射到等价、可独立检查的状态；不能只有 `courseId + artStep`。下面“允许保留”表示不必为了修复画质额外增加儿童操作。

### 01 `campus-contrast`：校园的两种节奏（compare）

- `lesson` 上课：教室内学生/书、窗户外动物静听；视线能分清内外。朗读标记落在读书者，静听标记落在窗外对象。
- `break` 课间：同一校园树下有不同于朗读的游戏姿态/伙伴活动；动物位置可看清。大青树与建筑保持连续。
- C：两选项不能仅切标记/字幕。V：两图比较能说出谁在何处做什么。M：动物“听读书”是文学想象，具体动物待核。

### 02 `flowers-imagination-links`：花与花孩子（association）

- `colours`→`clothes`：多色花瓣与多色衣裳的想象对应，颜色对象可见。
- `opening`→`holiday`：花开放与孩子走出学校相对应；自然/想象分层。
- `sway`→`arms`：花枝伸展摇动与花孩子伸手/舞动对应，不再只给开放结果。
- 允许保留关联卡。C：源卡ID决定当前观察对象，目标卡表示文学关联；错连不将花朵变成真实学生。V：开放与伸展两种姿态可辨。M：课文想象细节待核。

### 03 `question-change-route`：提问改变课堂（route）

- `doubt`：同一学生能背但疑惑，先生尚未解释。
- `ask`：学生面向先生提问，师生位置和注意方向明确。
- `recite`：按要求背功课，表现背书检查；不得仍显示提问动作，尽管旧数据同为 `artStep=1`。
- `understand`：先生讲解、同学听；不是仅把学生举手标签改成“理解”。
- 允许保留排序及移去重排。C：顺序 `doubt→ask→recite→understand`；选中最后节点才呈现该事件。V：四个动作阶段可辨。M：略读范围/具体反应待核。
