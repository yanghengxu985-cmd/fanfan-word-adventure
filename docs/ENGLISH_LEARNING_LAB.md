# 英语情景体验课

这是三个可操作样例，用来先确认学习方式，再决定是否扩展教材各单元。

入口：`#/english-lab`。三课分别是 `#/english-lab/cat`、`#/english-lab/greetings`、`#/english-lab/my-your`。教师演示在对应课链接后加 `/teacher`，不会保存个人作答。

## 体验流程

每课依次为 Learn（看图、听完整示范并显示英文）、Practice（带提示练习）、Check（隐藏目标文字的听懂检查）、Switch（换图、换地点或换角色）。所有声音均由点击启动，保留用户已选定的 Sonia 英式女声、-12% 合成速度。

| 样例 | 学习材料 | 换情景验证 |
| --- | --- | --- |
| cat | 两种猫的原创建模图，结合 A cat. 的声音与文字 | 第三只猫改变颜色、姿势与环境 |
| Hello / Goodbye | 两人走近见面，以及背书包走出门口告别 | 从学校转到公园与图书馆 |
| my / your | Lin 与 Lan 轮流介绍自己、问对方名字；示范高亮指向的姓名卡 | 更换说话人，交换人物左右位置 |

my / your 检查声音只读 My name. 或 Your name.，不直接读 Lin/Lan；图中说话人用气泡、口部和声音图标表示。题目的姓名选项不由左右位置固定决定。

最后两题由同一个人 Lan 说话，人物交换位置：Your name. 要选 Lin，My name. 要选 Lan；固定选择一个人物无法通过两题。六题的正确人物各出现三次。

## 语言和提示

孩子的活动页面使用短英文指令、声音和图片；默认不出现中文。Guide 会朗读一段简短操作指引，Listen and choose 指令可重听。Help 中提供按当前步骤解释的中文，只在主动打开时出现，返回后保持当前题目。

学习阶段显示目标英文；Practice 保留英文和正确图提示；Check 与 Switch 在首次选择前不显示目标词，也不在 SVG 里写目标词。选择之后显示英文供反馈和跟读。检查抬头也使用通用标题，避免从课名读出答案。

## 作答依据和复习

示范必须真正播放结束才开放下一步；题音必须完整播放结束才开放选择。Guide、指令和 Help 声音不能替代题音。播放失败、暂停、退出不会新增成绩。

每题仅保存第一次选择：Practice 或答题前打开 Help 都标记为 assisted；看反馈后的重试只供练习，不覆盖第一次错误。保存的能力为 listening，不记录为独立回忆或口语。连续多个日期选对也不会单凭这些选择题形成“跨日记住”。

复习背包根据已有体验课 listening 记录返回同样例，只检查需要复习的字词，跳过学习与带提示练习；其他能力仍返回各自玩法。教师模式不保存个人记录。

## 布局和素材

采用代码绘制的原创 SVG 与 CSS 动画，播放时人物走近或离开；暂停时冻结，降低动态效果偏好时保留清楚的静态情境。横屏并排、竖屏重排，下一步、暂停与 Help 保留在屏幕内。Help 使用可关闭的对话框。

该版本是三个样例，共8段学习示范、6题带提示练习、6题检查、6题换情景检查；不是完整学期改造。课本词库、旧课程入口和已有学习记录仍可以使用。音频为合成示范，未实现儿童口语发音评分。
