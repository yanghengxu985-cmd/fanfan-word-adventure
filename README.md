## 本地开发

下次使用可双击本目录的 `启动字词冒险岛.cmd`，或在 PowerShell 中执行：

```powershell
git clone https://github.com/yanghengxu985-cmd/fanfan-word-adventure.git
Set-Location -LiteralPath 'fanfan-word-adventure'
npm.cmd ci
npm.cmd run dev
```

按终端实际打印的 Local 地址打开。开发服务运行期间保持终端开启；启动脚本将固定使用5173端口，端口占用会提示失败，避免打开另一项目。需要换端口时用 `npm.cmd run dev -- --port 5174` 并按输出地址打开。源码和词库都保存在本地，关机不会丢失文件，下次重新启动服务即可继续。

`127.0.0.1` 是当前电脑的开发地址，供本地修改时预览；给老师使用上面的在线地址。课程使用hash链接，例如 `#/chinese-lesson/cn-01`、`#/course/en-01`、`#/teacher`，支持直接打开与刷新。旧语文课程、闯关链接会转到对应课件活动，原独立课件链接继续可用。

## 先试这几个入口

1. 语文森林：选单元，在课文或配套卡片上点一次打开；可自由切换阅读、字词和纸笔。返回时保留刚打开的单元和分类，不需要经过另一套全册目录。
2. 英语港湾 → 任一单元：试试“情景接话”和“听音寻宝”，也可以继续玩词义宝箱。拼写是自选练习，部分有同义表达的词不自动判拼写。
3. 教师课堂：选语文课件直接投屏，也可切到英语课堂。课件保留全屏、暂停、打印等适用控制，教师演示不写入个人成绩。
4. 家长手册：选择当前课和每轮4/6/8题，查看具体能力和复习日期，导入或导出学习备份。

“纸上写一写”目前是**拼音与释义提示的独立书写**，不是经过审听音频的听写。每题大人确认独立勾选；孩子自查只算练习。英语和中文口头回忆、开放句子填空采用揭晓后自查，避免把合理的不同表达判错。汉字仍由设备按例句朗读以减少孤立多音字误读；未验证读音的条目关闭声音按钮。

## 英语声音

英语采用已选定的英式女声 `en-GB-SoniaNeural`，在合成时使用 `-12%` 的清晰慢读速度。127条单元词语/表达（含选学）和26组字母都有固定MP3，同词共享音频。手机、电脑和老师投屏都播放同一份文件，无需安装英文系统声音。

点击小喇叭才加载当前词的声音，不会打开网页就下载整套音频。再次点击从头播放；切词、换课、换题或暂停时停止上一段。播放失败会提示重试。音频是AI合成的跟读示范，已经检查可解码、时长和音量，仍需教师审听发音；不冒充教材原音，也不自动评听力或口语。

音频随GitHub Pages一起托管，访问游戏不需要TTS API密钥。生成记录、字母和缩写处理、离线校验及重新生成方式见 [英语音频说明](docs/ENGLISH_AUDIO.md)。

## 英语全册闯关玩法

八个单元都有“情景接话”和“听音寻宝”，共104个原创活动。每个单元有6个情景任务，听辨题库通常为6题；Unit 7有14个听辨任务，覆盖数字1—10和car、book、ball、cake。常规每轮仍为4—6题，先从两个选项开始，再增加到三个；可以重听，选错后看示范再试，也可以自愿开口说一句，系统不做口语评分。后续单元沿用原版流程、布局和按钮，录音继续使用Sonia声线和`-12%`合成速度。

这两种新玩法采用适合平板的单屏布局：横屏把情景和选项并排，竖屏上下排列；反馈、“去下一站”和重试留在屏幕底部，无需向下寻找。详细示范、完整对话和开口练习通过弹窗打开，关闭后回到原题。老师投屏和英语新玩法复习也使用同一布局，退出关卡恢复课程页面的普通导航。

个人记录只保存每题首次作答：情景接话记为语境选择，听音寻宝记为听辨选择；它们不会单独计作独立回忆或“跨日记住”。看示范后的重试用于练习，老师投屏不保存个人进度。复习背包按原来的薄弱能力返回对应活动，听辨仍练听辨、语境仍练语境；到期项目较少时，复习轮次可少于4题。

词义宝箱保留原样。原24个活动与200个既有英语MP3保持原样，Unit 3—8追加80个活动和对应图片、语音。家庭成员按以Lin为锚点的关系图判断；数字图可以实际数出数量，动作图展示对应人物和工具。活动是配合教材词汇设计的原创练习，覆盖单元核心情景；详细逐单元范围、记录规则和教师用法见 [英语情境与听辨活动](docs/ENGLISH_ACTIVITIES.md)。

## 学习记录

进度记录在这个浏览器的localStorage中，不上传，不自动跨设备同步。另一浏览器、另一端口或托管网址都是不同的保存位置，需要手动导入备份。保存失败会保留本次会话记录并显示提示，应立即导出。

词义、语境、回忆、拼写、书写和听辨各自计算。选择题、同一天重复正确、看过提示，不会单独产生“跨日记住”。至少两个本地日期的无提示独立证据才升级已测能力；书写需家长或老师确认。复习保留原来的薄弱技能，按1/3/7/14天安排；这是当前产品规则，不是保证永久掌握的结论。

导入先检查格式、版本、词条ID、时间和重复记录，检查通过后由界面确认替换。不合法备份不会改动原记录；请先导出原记录。更换浏览器或清理缓存前也请备份。

语文按浏览、字词练习、纸笔核对和具体待练项分别展示，不把浏览或勾选次数当成掌握。全记录备份包含主进度及语文旧样板、通用纸笔、《山行》纸笔、课程浏览四类辅助记录。导入旧版字词备份只替换主进度，保留现有辅助记录；全记录导入按确认的备份替换这五类数据。偏好设置和其他项目的浏览器数据不包含在备份中。

纸笔复查只更新本课、同一目标与对应证据类型。匹配的字词书写（或会写字的看字记忆纸写）可把旧书写提醒移到下一个本地日期；纸稿中仍勾为错项的内容立即留在待练区。它不抹除其他能力的提醒，也不生成跨日独立书写或整课掌握证明。规则和完整验证见 [语文森林整合说明](docs/CHINESE_FOREST_INTEGRATION.md)。

仓库使用公开源码和 GitHub Pages；发布流程见 `.github/workflows/deploy.yml`。首次在仓库 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`。工作流使用 Node 24，依次安装锁定依赖、运行自动测试、构建 `dist/` 并部署；测试或构建失败不会发布新版本。

推送 `main` 或在 `Actions` 手动运行即可发布。可以在工作流的 `Deploy website` 查看结果和网址。`base: './'` 配合hash路由支持仓库子路径；更换仓库名时也要更新本说明中的网址。

本地浏览器快照、学习记录导出、环境文件、依赖和构建目录已在 `.gitignore` 排除。发布文件是 `dist/` 中的静态资源，学习记录继续保存在访问者自己的浏览器中。学习记录从本地预览迁到线上时，先在旧地址导出，再到线上家长页导入。

页面基于 [React](https://react.dev/learn) 和 [Vite](https://vite.dev/guide/)，没有引入业务数据库或运行时收费API。SVG工具图、英语插图和27幅原创语文WebP插图随网站托管，无运行时远程字体或图片依赖；插图与课件按页面加载。

真实浏览器检查使用Playwright CLI独立QA浏览器会话，不读写用户日常浏览器的学习数据。复查脚本在 `scripts/browser-check.js`，`scripts/browser-check-activities.js` 检查英语活动与真实音频，`scripts/browser-check-ipad-layout.js` 检查5种平板视口内的按钮位置、字号和不滚动换题。截图和测试备份在 `output/playwright/`。具体结果见 `实施与验收记录.md`。

本次森林整合通过243项自动检查和生产构建；三种平板视口的真实目录与返回路径、教师入口、纸笔复查和全记录备份均已复查。见 [整合验收](docs/CHINESE_FOREST_INTEGRATION.md)。视口模拟不等于实体iPad或实际课堂效果验证。
