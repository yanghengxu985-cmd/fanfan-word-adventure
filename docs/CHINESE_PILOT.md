# 三上语文两课样板

本次范围：按现有教材目录建立全学期清单，先实现第1、4课可用样板。现有英语活动、音频与布局保持原样。

## 入口与使用

- 全册清单：`#/chinese-plan`，26课和目录实际7个园地，按单元/字词搜索，可下载MD与CSV。
- 第1课：`#/chinese-pilot/cn-01`。
- 第4课：`#/chinese-pilot/cn-04`。
- 老师演示：`#/chinese-pilot/cn-01/home/teacher`，以及第4课对应链接。每个具体玩法路径末尾加`/teacher`；演示不计个人记录。
- 错项小册与独立备份：`#/chinese-pilot/review`。

汉字侦探每课12道，涵盖字音、形近字和组词辨认。每轮6题，选项位置随机，优先抽未练题，首次作答记录结果。这类识别证据不等于独立会写或能自主组词。

字词参考覆盖两课所有认读字与会写字，按本课语境标拼音并提供两个原创组词参考。让孩子先口头组词，再看参考；开放组词由家长/教师核对，不拿固定示例判错。第1课的11个新版词表词全部进入纸写题库；为覆盖全部会写字另加皮球、招呼、读书3个原创练习。第4课11个组词纸写为原创生字练习。

纸写每轮最多6项。看拼音或点击听词语，孩子在纸上写，点击下一题；题目不会提前显示目标字或答案。不会的题可以跳过，跳过在集中核对中固定勾为错项。整轮结束才显示答案，核对错字、漏字、标点。大人确认必须查看**揭晓前写好的纸稿**；看答案补写为订正。系统不自动识别手写，也不自动评分口头背诵。

第4课三首古诗原文可逐行听读。六项诗句接力是有上句提示的补写练习，不代表会默写整首。《山行》另有无诗句提示的四句整首纸默。只有《山行》标为教材默写要求，其余两首为背诵/补句练习。2025公开预览p15确认范围，2026纸本课后页尚待复核。

## 记录与复习

使用独立键`fanfan-word-adventure:chinese-pilot:v1`；不修改英语/原进度格式。题目ID与能力类别绑定，字音选对不能清掉同字的纸写错项。

- 选项题：只记识别结果。
- 纸写、补句、整首默写：自己核对记录练习；大人确认、未看答案的正确纸稿才算独立纸写。
- 错项：隔1天复习；在不同日期经有效核对正确，再按3/7/14天安排。同日订正不推进间隔；自查纸稿不推迟原来的独立复习。
- 重复提交同轮去重；导入核版本/题目/能力/结果/时间/重复。先显示备份条数，确认才替换；非法导入保留原记录。
- 存储失败仍保留当前内存结果，结果页可导出包括本轮的备份。换设备需在错项小册单独导出/恢复，原家长手册备份不包含此新记录。

## 数据与边界

`chinesePilot.json`定义两课内容，`chinesePilot.ts`派生整首纸默与抽题。`chineseSemesterPlan.json`和MD由`scripts/export-chinese-plan.mjs`同步生成；`node scripts/export-chinese-plan.mjs --check`检查一致性。全册记录中399条拼音有核对依据、377条待核，仅两课可用样板，不宣称全册背默游戏已完成。

中文音频45段固定文件，`zh-CN-XiaoxiaoNeural`合成`-8%`、正常速率播放，换题/切诗/退出停止；技术验证与家长/教师实际审听分别标记。古诗属公版，现代课文全文未发布。
