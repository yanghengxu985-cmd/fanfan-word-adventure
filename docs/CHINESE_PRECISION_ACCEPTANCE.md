# 全册精修：审核与验收规则

本次授权覆盖26课与23项配套，先检查全册规划，再按课审核制作。现有《总也倒不了的老屋》《搭船的鸟》《金色的草地》保留。本文与全册规划共同约束制作，不把同一模板改标题当作逐课完成。

## 规划通过的条件

每个条目有明确学习目标、适合该目标的主交互、孩子独立说明或纸笔检查的办法，并区分教材要求与原创辅导。主交互应让孩子观察、比较、关联、梳理或表达，而非只读讲解与选择明显的词义。

1. 目录、课名、单元、略读属性与家长照片一致；两课古诗各覆盖三首。
2. 会认、会写、课内词语使用项目现有版本清单，2026纸本未核项保持待核。略读课不能新增必写任务。
3. 预测只根据已经读到的信息；合理不同预测可以保留，不以猜中作者安排判成绩。
4. 现代文提供原创概述和辅导，公版诗文可显示原文。科学、历史和城市插图是示意，不是实景、测量或史实证据。
5. 写作从孩子真实经历与观察出发，不生成代写全文；口语允许双方直接换角色、追问与复述。
6. 园地正式栏目、日积月累、指定素材与未核背默不能用旧版内容补造。可提供明确标注的原创单元复习，但不称教材原页已完整复现。

## 每课制作后的审查

- 内容：逐课对照目标与已有可靠材料；反馈是否解释依据；图片是否误导或泄露后文；待核范围是否显著说明。
- 功能：每个主工具实际改变图景、观察位置、关系、顺序或表达材料；可直接切页；原选择、草稿、预测在切页后保留，不强制连续步骤。
- 字词：读音以已核语境为准；遮字时检查页面标题、辅助提示、弹窗与打印是否泄漏答案；认读不能自动算会写。
- 音频：有音频的入口实际播放；切页、换词、隐藏页面及离开时停止。声音示意要说明是合成或模拟。
- 教师：独立链接可投屏；不读写个人学习成绩；课堂提问与一页纸笔记录可用。
- 排版：1024×768、1024×700、768×1024逐项检查；核心操作在屏幕和内容区域内，可实际点击；允许字库分组，但翻组控件固定可见。
- 视觉：逐课查看截图，不以DOM尺寸检查替代人工画面审查；插图、文字、图示与按钮有清晰层级。
- 打印：A4页数实际检查；内容不裁切；独立练习先不填答案，遮字状态打印不露字。
- 回归：保留英语与三篇专属精修的行为；代码测试与正式构建通过，公开网址确认后才记录已发布。
