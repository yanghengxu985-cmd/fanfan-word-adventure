# 语文森林整合与验收

日期：2026-10-04。26课和23项配套的工具已完成制作；2026纸本正文、未核背默范围及园地实际栏目继续标注待核。

## 统一入口

- [语文森林](https://yanghengxu985-cmd.github.io/fanfan-word-adventure/#/map/chinese)：8个单元，每次显示当前单元的课文或配套；卡片点一次直接打开课件。搜索查全册，结果每页最多4项。
- [教师课堂](https://yanghengxu985-cmd.github.io/fanfan-word-adventure/#/teacher)：同一套单元目录，直接进入投屏模式。
- [语文复习背包](https://yanghengxu985-cmd.github.io/fanfan-word-adventure/#/review/chinese)：分别查看字词能力提醒和纸笔错项，回到对应课的字词或纸笔页。

范围是26课＋23项配套，共49项；两组《古诗三首》中的6首分别有工具。配套含8项习作、4项口语交际、7个园地、1个读书吧、2篇例文及期末复习；第5单元没有园地，不补造栏目。

课内各活动直接切换，不设前置关卡。原独立链接继续可用；旧语文课程与闯关链接转到对应阅读、字词或纸笔活动。返回森林或教师目录时保留原单元和课文/配套分类。家长与教师资料页收纳全册规划、词表和审核记录。

## 记录与纸笔规则

森林显示当前课，并分别展示已浏览、字词练习次数、纸笔检查次数和待复习项。浏览、看过解释或勾过核对均不是“掌握”。教师浏览事件不读取或写入孩子的浏览记录；教师课件不读取或保存个人纸笔记录，也不写入练习成绩。

纸稿仍须由孩子实际完成，再对照核查；成人勾选只说明这次核对，不能证明揭晓前独立完成。纸笔错项只按本课、同一目标和对应证据类型消除；选择题正确不能清除书写、背诵或默写错误。

旧主进度中的`writing`提醒与新纸笔记录保留各自证据。较新的同课同目标字词纸写，可把该书写提醒延到下一个本地日期；会写字的看字记忆纸写可同样续期。诗句核对、其他课或其他目标不能续期。纸稿上仍勾为错误的目标立即留在待练区。续期不改写历史，不增加跨日独立证据，也不取消字义、回忆等其他能力的提醒。

## 全记录备份

家长页导出主字词进度，以及四类辅助记录：旧语文样板、通用语文纸笔、《山行》纸笔、课程浏览。记录留在当前浏览器，不自动跨设备同步；换设备时手动导入。

全记录导入先完整校验，再经界面确认替换五类数据；中途保存失败尝试恢复原记录。旧版字词备份只替换主进度，保留四类辅助记录。偏好设置与无关项目数据不被导出或替换。损坏备份不写入；原存储无法读取时不生成可能误导为空的全记录备份。
