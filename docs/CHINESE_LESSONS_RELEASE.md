# 三上语文逐课课件

全册入口：https://yanghengxu985-cmd.github.io/fanfan-word-adventure/#/chinese-book

## 已实现

- 26课分别制作原创讲解与情境插图，每课4个步骤；故事、观察、写景、预测和文言使用不同活动。
- 两课古诗共6首：望洞庭、山行、夜书所见、鹿柴、望天门山、饮湖上初晴后雨。提供全文、逐句拼音与诗意、切换诗景、朗读、遮字背诵和纸笔检查。
- 课文和园地的已整理三表完整保留：276条识字表展示项、250条写字表项目、250条词语表项目。重复认读字按课内语境分别保留。
- 377段静态中文音频：249个已核读音的词语、104段原创讲解、24行公版诗句。使用既有中文示范声音；词语“起来”仍待核音，不加入拼音纸写。未核单字不显示猜测拼音。
- 23项配套活动：8习作、4口语交际、7园地、快乐读书吧、2习作例文、原创期末复习。具体提纲、短草稿、口头轮次、遮字纸写与人工核对可直接操作。
- 教师投屏、资料指导和一页A4练习纸；主要操作按钮固定在页面底部。模块直接选择，预测课先说猜想和依据，再展开后文与完整理解题。
- 字词自查、成人核对记录分开，选择题不转成独立书写或长期掌握。记录只在本浏览器保存；教师模式不显示或保存个人纸写记录，配套短草稿离开模块即清空。

## 教材范围

目录和页码对应家长提供的2026纸本照片，基础字词按同目录公开预览整理。2026纸本正文、三表以及大部分课后背默要求尚未逐页复核。第4课同目录预览已明确背诵三首、默写《山行》；其他待核范围不默认追加为必背、必默。

园地一、二、六尚无已整理的专属字词数据，使用对应单元课文字词做明确标注的原创复习；园地栏目和日积月累原文待纸本核对。例文页辅导孩子修改自己的观察与草稿，不提供可照抄的整篇范文。

现代课文讲解是原创归纳，配合手边教材阅读；古诗与文言展示公版原文。情境插图为原创教学想象，音频为合成练习示范，技术验收不等于教师逐段审听。资料链接保留在原网站，不搬运网课或第三方课件。
