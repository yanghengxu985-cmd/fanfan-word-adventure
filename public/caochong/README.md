# 曹冲称象 · 河岸上的小实验

访问地址：https://yanghengxu985-cmd.github.io/fanfan-word-adventure/caochong/

## 使用

使用电脑浏览器或 iPad Safari 打开，横屏操作。可通过 Safari 的共享菜单添加到主屏幕。

1. 请大象上船，观察船下沉。
2. 在船身与水面相交处做记号。
3. 请大象下船，组合石头，直到黄色记号与水面重合。
4. 点选或拖动船上任意一块石头到左秤盘；等天平自动配平后，点击“记下来”。
5. 根据称量本计算总重量。答对后回放大象和石头的同水位状态。

支持取回石头、撤销组合、静音、朗读、随机重量挑战和减少动态效果的系统设置。音效由 Web Audio 在本地合成，在用户操作后启用，不需要下载音频。

## 文件与发布

`index.html` 是完整的独立课件，图像、样式、逻辑和声音均嵌入其中，下载后也能离线运行。文件中的 `lesson-engine`、`lesson-audio`、`lesson-ui` 三个脚本分别负责教学状态、轻音效和交互动画。

本目录放在 Vite 的 `public` 中，现有构建会将其复制到 `dist/caochong`；main 分支提交沿用仓库已有 GitHub Pages 自动部署。无需更改原应用入口、依赖或发布工作流。

## 验证

提交前完成 12 项教学与载重状态检查、4 项动画回调与重置检查、4 项音效开关与降级检查，并通过脚本语法和单文件依赖检查。天平静止和摆动关键帧已做静态 SVG 视觉检查。浏览器及真实 iPad 的触控、布局、音量尚未实测。

船体和称量台均为教学示意：同一艘船、同样的水、相同水位记号对应相同载重。砝码由课件自动配平，图形尺寸不代表实物尺寸。
