# 三年级上册语文与英语字词闯关游戏：开发任务

编写及优化日期：2026-10-03。本文包含产品形式、教材词库、实现范围、数据规则和验收要求。用户已授权开始本地实施，应用源码位于本仓库根目录；数学云端项目单独维护。下列长期目标与本次本地版本的交付范围分开验收。

## 1. 项目目标

为凡凡制作一套与本学期教材对应的字词闯关游戏。孩子每天完成一小段有明确终点的任务，通过认读、主动回忆、书写或口头表达、语境应用及间隔复习掌握字词。老师能够选择对应课文或单元，投屏进行听辨、辨字、选词和对话活动。

产品暂名：**凡凡字词冒险岛**，名称与角色可以替换。

游戏需要解决的是“这些字词哪种能力已经掌握，哪种能力还需要帮助”。不以点击次数、在线时长或积分多少证明学会，也不承诺考试排名。语文阅读、习作和英语听说能力另有完整教学要求；本项目通过简短句子和场景任务连接这些能力，不把字词游戏包装成全部学科学习。

### 1.1 本次优化后的实施目标

先交付一套可以实际学习、留下可靠记录、供老师演示的本地网站。全学期词库一次落地，玩法按字段就绪情况开放。没有读音、释义或正文依据的条目保留在课程里，不用猜测填满题目。

产品成效以“相同时间内能独立解释、回忆并隔天保持更多字词”为试用观察目标。首轮试用一周，记录具体词条的提示使用、不同日期复测和孩子的负担感，调整题量与反馈；不把分数、时长或单次闯关数当作有效性结论。

## 2. 教材版本与依据

### 2.1 语文

- 教育部组织编写、人民教育出版社《义务教育教科书 语文 三年级 上册》。
- 用户版权页：2025年6月第1版，2026年7月第2次印刷。
- ISBN：978-7-107-39754-7。
- 用户提供的目录为26课新版；新增或调整课文包括《犟龟》《宝葫芦的秘密（节选）》《香港，璀璨的明珠》《一定要争气》等。
- 识字表从教材第109页开始，写字表从第112页开始，词语表从第114页开始。最终收录范围以用户纸质教材这些表的全部页面为准。

### 2.2 英语

- 译林出版社《义务教育教科书 英语 三年级上册》，三年级起点。
- 用户版权页：2024年7月第1版，2026年7月第3次印刷。
- ISBN：978-7-5753-0037-7。
- 用户目录为2个Module、8个Unit的新教材，Word lists从第78页开始，英语字母表在第83页。
- 正确的Unit 2为 **What's your name?**；不能把旧版Unit 2 **I'm Liu Tao / Are you Liu Tao?** 的词表整体替入。

### 2.3 词库核验规则

本文末尾列出的词库必须保留来源与核验状态。来源层级如下：

| 状态 | 含义 | 在游戏中的处理 |
| --- | --- | --- |
| `paper_verified` | 与用户2026印次纸质教材逐项核对 | 可列为教材正式学习清单 |
| `preview_verified` | 已核读同版、同目录的公开词表预览，尚未复核用户纸本印次 | 可作为标明状态的开发和内测数据，正式教材覆盖验收前复核 |
| `pending_verification` | 归属、读音、字形、译义或教材要求仍有疑点 | 留在待核对清单，不生成会被判错的正式题目 |
| `extension` | 原创练习补充或教师新增 | 单列为拓展，不计入教材表覆盖率 |

“列出了全部可核读词条”与“已核对用户这一印次的全部教材要求”是两种不同状态。不要根据网站标题中的“2025新版”就认定内容匹配，也不要用词库数量反推书写要求。

## 3. 做成什么形式

### 3.1 一套网站，两条学期路线

首页提供语文和英语两个入口，以及“今天的任务”“复习背包”“家长查看”“老师投屏”。语文按8个单元、26课组织；英语按2个Module、8个Unit组织，另设字母活动和2个Project。

地图中的每课是一处可进入的小场景。进入后先看到本课词条与目标，再开始关卡。已经掌握的内容可通过小检查跳过，不要求机械重做。所有课和单元都能独立打开并分享链接。

首版使用轻量的绘本式2D场景、清晰大字、简单角色和短反馈动画。奖励表现为修复岛屿、收集书页或解锁小故事；视觉表现服务字词任务，不遮挡题目，不通过长动画拖延答题。

### 3.2 一次游戏的基本流程

1. 看今天的任务：到期复习、当前课内容与少量应用题。
2. 遇到陌生词先学习：显示字形、正确读音、简明词义和原创例句，可以重听。
3. 进行辨认与练习：根据当前能力选择题型，答错给具体差异解释。
4. 完成一次无选项的回忆或表达，再在新句子/场景中使用。
5. 显示本次学会的能力与需要复习的项目，明确“今天完成了”。

单日两科合计可先以10至15分钟作为可调整的试用目标。家长可设置题目上限和学习时长提示，孩子可随时暂停。这个时长是产品起点，不是经过证明适用于所有孩子的最佳值。

### 3.3 页面清单

| 页面 | 必须完成的功能 |
| --- | --- |
| 首页 | 学科入口、今日任务、当前课、复习数量与最近继续入口 |
| 学期地图 | 全部单元与课、词库核验标记、进度；课目可直接选择 |
| 每课词卡 | 按会认/会写/词语或英语能力展示，查看读音、解释、例句 |
| 闯关页 | 大字题目、音频、操作区、反馈、暂停、退出、继续 |
| 听写页 | 一次一个词，重听，隐藏答案，写完后统一核对 |
| 复习背包 | 按具体能力查看到期词、易混词、再次尝试记录 |
| 单元挑战 | 已学内容混合出题，包含独立回忆和新语境任务 |
| 家长页 | 具体词条与能力、需要帮助的原因、安排进度、导入导出 |
| 教师页 | 选课、选题型、投屏、答案隐藏、讲解、纸质练习导出 |

界面不显示数据库、API、模型、核验代码等实现术语。教材来源与待核对说明放在家长/教师信息和内容说明中；学生看到明确的学习目标与正确解释。

## 4. 语文关卡设计

### 4.1 能力分开记录

每个汉字或词语分别记录：`字音辨认`、`字形辨认`、`词义理解`、`语境运用`。属于写字表的字及相应重点词语另记录 `独立书写`。识字表中仅要求认识的字不自动增加强制默写任务。

### 4.2 题型

| 关卡 | 玩法 | 必须提供的教学反馈 |
| --- | --- | --- |
| 听音找字 | 听词或句子，选择对应字词 | 错在哪里：音、字形还是词义 |
| 字形侦探 | 在有语境的题目中区分形近字 | 标出易混部件，解释差异，不靠位置暗示答案 |
| 多音字小路 | 根据具体词语或句子选择读音 | 读音必须绑定该词义和语境，不给单字设唯一读音 |
| 词义宝箱 | 用图、短解释或情境对应词语 | 解释适用条件，不把相近意思简单判为完全相同 |
| 选词搭桥 | 将词语放入句子，必要时说明理由 | 承认有依据的多种答案，解释更贴切的选择 |
| 独立回忆 | 隐藏候选项后说出、读出或纸上写出字词 | 与有选项辨认分开计分；家长确认流程明确 |
| 词语小故事 | 在新的原创短句或2至3句小情境中理解和使用 | 指向词义、搭配和表达，不要求复述固定模板 |

“拆字组合”仅对经过核验的部件拆分开放；不能为了拖动游戏随意拆笔画、编字源或把不独立的部件命名为另一个汉字。

### 4.3 书写验证

- 首版必须提供纸上听写：播放字词，孩子书写，最后显示标准答案，可标记错字位置和错因。
- 可以提供屏幕描写/手写练习；描红完成只记录练习，不自动证明会默写。
- 用输入法选出正确汉字只记为认读或输入表现，不记为独立书写通过。
- 自动手写识别与笔顺判分为可选后续功能。未经验证时，不据此单独判定错误或稳定掌握。
- 标准字形、笔顺、部首和多音字读音要有可查依据；有疑问的词条进入待核对队列。

## 5. 英语关卡设计

### 5.1 能力分开记录

分别记录 `听懂`、`认读`、`词义理解`、`口头运用`、`拼写`。教材或老师没有明确要求独立拼写的词，默认拼写为练习选项，不作为该词通关门槛。专名、感叹词、缩略形式和完整短语分别归类。

### 5.2 题型

| 关卡 | 玩法 | 教学要求 |
| --- | --- | --- |
| 听音寻宝 | 播放单词或短语，选择图片/人物/动作 | 答案隐藏文字，检查是否听懂而不是照着字形匹配 |
| 看图认词 | 图与词匹配，随机位置 | 只能测辨认，后续安排独立回忆 |
| 词音连接 | 听音找到文字，或看到词后听审读音 | 不将字母名称当作所有词中的字母读音 |
| 看图说词 | 隐藏选项，孩子说词；可听示范并录音回听 | 示范、回放和家长确认可独立工作 |
| 字母与拼写 | 大小写匹配、字母顺序、符合教学要求的词拼写 | Aa至Zz完整覆盖；大小写、空格与标点规则明确 |
| 句型搭桥 | 把词放入当前单元句型，选合适回答 | 保留完整表达，不仅做英文和中文配对 |
| 角色小剧场 | 在认识朋友、介绍家人、生日、帮助家人情境中轮换角色 | 换人物、图和条件仍能表达，不只是背原按钮顺序 |

### 5.3 8个单元的场景

| 单元 | 用户目录确认的标题 | 建议游戏情境与应用关 |
| --- | --- | --- |
| Unit 1 | Hello! | 校门打招呼，选择合适问候，与不同角色轮换 |
| Unit 2 | What's your name? | 给新朋友制作名牌，询问和介绍名字 |
| Unit 3 | Are you Su Hai? | 认人和确认身份，按人物条件选择回答 |
| Unit 4 | This is my friend | 向另一个角色介绍朋友，换人物继续表达 |
| Project 1 | Making friends | 汇合前4单元，完成一张原创交友卡和短对话 |
| Unit 5 | She's my mother | 家庭相册，介绍人物与关系 |
| Unit 6 | Is he your grandpa? | 找到相册人物，询问并确认家庭关系 |
| Unit 7 | Happy birthday! | 生日场景，按教材内容完成祝福、年龄或相关问答 |
| Unit 8 | I can do this for you | 为家人做事，表达能做什么；动作与词义同步 |
| Project 2 | My family poster | 制作家庭海报，组合人物介绍和帮助家人的表达 |
| Alphabet | Aa至Zz | 大小写、字母名称、顺序与原教材相关活动 |

表中情境为开发建议；具体词项、句型、数词范围、书写层级需依据末尾词库和教材正文核对，不凭情境自动扩入新词。

### 5.4 音频与口语

- 优先使用用户有权使用的教材配套音频；没有可分发授权的音频时，使用有许可的原创录音或语音合成。
- 使用合成语音要人工听审姓名、缩写、孤立单词与完整句子；课内英语使用一致的口音规范，并允许重听。
- 播放错误时显示可理解的重试提示，不能把资源未加载当作学生不会。
- 可录音回听和对照示范。录音默认不上传，需明确的家长操作才启用后续云处理。
- 首版不强制使用AI发音评分。任何自动评分只作为辅助，不因一个分数判定儿童一定读错。

## 6. 通关、掌握与复习

### 6.1 三种不同状态

1. **练习过**：看过解释、描过字、跟读过或借助提示答对。
2. **本次通过**：本轮独立答对，记录题型与是否使用提示。
3. **稳定掌握**：在至少两个不同日期，通过相应能力的复测，其中包含无选项回忆或新语境应用。

稳定掌握的具体阈值可配置；初版将“至少两个日期”作为产品规则，不宣称这能永久证明掌握。一次忘记只调整相关能力，不清除其他已经掌握的能力。

### 6.2 复习调度

- 可先采用1、3、7、14天的可调整复习安排，按实际错误和提示使用情况缩短或延长间隔。
- 每日优先处理已到期和薄弱项目，限制新增数量；同一词在同一轮中换方式提问。
- 以本地自然日计算复习日期，正确处理午夜、时区与修改设备时间，不因换日期丢失记录。
- 答错后先解释，再稍后独立重试。立刻展示答案后重复点正确项不计入稳定掌握。
- 奖励纠正错误、完成回忆和复测；默认不倒计时，不设置连续登录惩罚，不使用公开成绩排名。

学习依据：主动回忆、间隔学习和解释性问题可参考[美国教育科学研究院学习指南](https://ies.ed.gov/ncee/wwc/practiceguide/1)。具体游戏阈值、时长和奖励机制属于本项目设计，需要试用调整；不能把上述研究解释为已证明这款游戏能提高考试名次。

## 7. 家长与老师用途

### 7.1 家长

- 按学校实际进度选当前课，查看全学期地图。
- 查看具体词条及能力，例如“认得，但独立写字仍需复习”，而不是只有一个总分。
- 设置任务上限，开启纸上听写，确认手写或口头表达结果。
- 可编辑个别词条的教学要求，新增老师补充词；教材原表与补充词始终区分。
- 导出/导入学习记录，备份后跨设备手动转移。

### 7.2 老师

- 从单元或课直接进入，投屏时大字号、答案隐藏、鼠标和键盘均可控制。
- 一键选听辨、辨字、词义、拼写或句型题型，暂停和回看解析。
- 提供当前课完整字词清单和纸质听写/练习导出。
- 首版没有全班学生账户与在线汇总。教师查看学生个别进度须导入该学生记录；没有记录时不显示虚假的“全班掌握率”。

同一个字可能出现在多个词和多个单元，词条出现次数与去重后的词条数量分别统计。汉字认读与写字要求可对应同一个字形，但能力与课程归属不能被合并丢失。英语`class`的不同含义、`one`的词性与语境、缩略形式和专名同样需要保留。

词条ID在纠正拼写或调整课程顺序时保持稳定；教材换版时使用新的editionId，并定义进度迁移，不能把新词误继承为旧词已掌握。

### 8.2 每道题必须含有

- 题目ID、关联词条、目标能力和课程。
- 提示方式、音频或图片、允许的操作、答案或可接受答案集合。
- 针对每个错误选项的教学说明；多种正确表达不能硬判错。
- 提示使用记录、是否属于独立回忆、是否为新语境。
- 随机化规则与可复现种子，保证开发测试能复现问题。
- 来源与核验状态。原创例句不得改变被测词的正确读音或词义。

对每个正式词条至少提供学习卡、适用的辨认题、对应能力的回忆任务与语境任务。题目不必一律同样数量或题型；语法词、专名、感叹词、字母等不适合图像配对的内容必须采用合适方式。

- `for`：U7 p62 是递物、礼物等语境中的“给”；U8 p66 是为家人做事。不能把两个义项错误合并为一组汉译英题。
- `love`：U6 p55 用于爱家人；U7 p62 可表达喜欢物品。
- `mum / mom`、`Mr / Mr.`：接受词表列出的英美写法，语音不得朗读括号内说明。
- `grandfather / grandpa`、`grandmother / grandma`：均列入可认读词形；家庭关系题接受相应同义称呼。
- `child / children`：存储单复数关系，儿童数量明确；不能把 children 判为 child 的拼写错误。
- 短语中空格和撇号须规范；可接受直撇号和弯撇号；英文大小写的语义要求与标点分开评分，不能因为末尾缺感叹号判为词义不会。
- 本表没有把 `birthday`、`morning`、`afternoon` 等从表达中拆成“新增核心词条”。可作为组件练习，但要标记 `derived_component`，不得抬高教材词表覆盖统计。

#### 缩略形式：单独的语境练习

以下 7 组有原书标题、脚注或词表表达支持，作为缩略式与完整式的对应练习，另计而不混入前述 127 条。

| 缩略形式 | 完整形式 | 原页证据 |
| --- | --- | --- |
| I'm | I am | U1 p10 |
| what's | what is | U2 p18 |
| you're | you are | U3 p28；U7词表 You're welcome. |

| she's | she is | U4 p37 |

完整式在连词成句和补全对话中也接受。不要将 `it's` 与物主代词 `its` 混为一项；`isn't` 等未在本次所核原页证明的项目只能由教师增补，不冒充本表确认项目。

#### 专名：用于人物卡，不作主线默写

原书 Word lists III 第 82 页共 11 个专名记录：`Bobby`、`Sam`、`Mike Brown`、`Mr Green`、`Jake`、`John`、`Max`、`Willy`、`Tina`、`Tad`、`New Year's Day`。

人物页和已核原页还出现 `Su Hai`、`Su Yang`、`Yang Ling`、`Liu Jiajia`、`Miss Li`、`Wang Bing`、`Liu Tao`、`Mike`、`Zhang Hua`、`Beibei`。它们用于介绍人物、区分身份和对话替换，不按“普通单词不会拼写”记错。以上是本次已核角色，不声称覆盖全册每个故事的全部专名。

`New Year's Day` 属于节日与故事情境。新教材编写者明确以 U8 为例，区分核心能力表达与情境支撑词汇；因此不能为了“全内容”要求孩子额外死记所有故事旁白。[何锋、宫文胜：译林版小学英语新教材的理解与使用](https://flts.bnu.edu.cn/node/16681)
