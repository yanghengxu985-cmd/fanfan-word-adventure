## 本地开发

下次使用可双击本目录的 `启动字词冒险岛.cmd`，或在 PowerShell 中执行：

```powershell
git clone https://github.com/yanghengxu985-cmd/fanfan-word-adventure.git
Set-Location -LiteralPath 'fanfan-word-adventure'
npm.cmd ci
npm.cmd run dev
```

按终端实际打印的 Local 地址打开。开发服务运行期间保持终端开启；启动脚本将固定使用5173端口，端口占用会提示失败，避免打开另一项目。需要换端口时用 `npm.cmd run dev -- --port 5174` 并按输出地址打开。源码和词库都保存在本地，关机不会丢失文件，下次重新启动服务即可继续。

`127.0.0.1` 是当前电脑的开发地址，供本地修改时预览；给老师使用上面的在线地址。课程使用hash链接，例如 `#/course/cn-01`、`#/course/en-01`、`#/teacher`，支持直接打开与刷新。

## 先试这几个入口

1. 首页“开始今天的冒险”：查看《大青树下的小学》的词卡，选择“词义宝箱”或“回忆小路”。
2. 英语港湾 → Unit 1：词义理解与口头回忆。拼写是自选练习，部分有同义表达的词不自动判拼写。
3. 老师投屏：选择课目和玩法，先提问，再揭晓答案；可以全屏或打印本课词单，演示不保存个人成绩。
4. 家长手册：选择当前课和每轮4/6/8题，查看具体能力和复习日期，导入或导出学习备份。

“纸上写一写”目前是**拼音与释义提示的独立书写**，不是经过审听音频的听写。每题大人确认独立勾选；孩子自查只算练习。英语和中文口头回忆、开放句子填空采用揭晓后自查，避免把合理的不同表达判错。设备朗读只供跟读示范，汉字按例句播放以减少孤立多音字误读；未验证读音的条目关闭声音按钮。

共929条记录。识字表276个展示项含旧字的多音复习，教材标注250个新生字；不能把276称为新生字数。同一字在认读和写字表保留不同来源记录，每项能力分别统计。英语127条包含短语，去重词头为123，12条星号词为选学，不默认加入主路线闯关。7组缩略形式、11个专名另列在结构化资料中。

26篇语文课文和8个英语Unit都已有可玩的词义关卡；已有释义和例句的条目可以做相应回忆/语境任务。中文249个词语和148个汉字教学记录有编辑后的简释，英语127条已具备释义和原创例句；缺字段的词卡保留，依赖这些字段的题型不开放。游戏内的原创简释和例句仍需教师试用审阅。

语文园地1、2、6正文词项以及英语两个Project具体任务待补全。Projects当前只汇集相关单元词卡，不能当作已经完成了主题活动。`起来`、`贞`和尚未明确课内读音的多音字保留疑点并禁用相应判题。2026纸本印次尚未逐项核对，不宣称用户整本教材已完成100%教学覆盖。

正式题目只使用达到对应字段门槛的条目。自动拼写不把合理同义词当错字，语境挖空后仍出现目标答案的题目会关闭。星号选学词仍可以在本课词卡里查看。

## 学习记录

进度记录在这个浏览器的localStorage中，不上传，不自动跨设备同步。另一浏览器、另一端口或托管网址都是不同的保存位置，需要手动导入备份。保存失败会保留本次会话记录并显示提示，应立即导出。

词义、语境、回忆、拼写和书写各自计算。选择题、同一天重复正确、看过提示，不会单独产生“跨日记住”。至少两个本地日期的无提示独立证据才升级已测能力；书写需家长或老师确认。复习保留原来的薄弱技能，按1/3/7/14天安排；这是当前产品规则，不是保证永久掌握的结论。

导入先检查格式、版本、词条ID、时间和重复记录，检查通过后由界面确认替换。不合法备份不会改动原记录；请先导出原记录。更换浏览器或清理缓存前也请备份。

## GitHub Pages 自动发布

仓库使用公开源码和 GitHub Pages；发布流程见 `.github/workflows/deploy.yml`。首次在仓库 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`。工作流使用 Node 24，依次安装锁定依赖、运行37项测试、构建 `dist/` 并部署；测试或构建失败不会发布新版本。

推送 `main` 或在 `Actions` 手动运行即可发布。可以在工作流的 `Deploy website` 查看结果和网址。`base: './'` 配合hash路由支持仓库子路径；更换仓库名时也要更新本说明中的网址。

本地浏览器快照、学习记录导出、环境文件、依赖和构建目录已在 `.gitignore` 排除。发布文件是 `dist/` 中的静态资源，学习记录继续保存在访问者自己的浏览器中。学习记录从本地预览迁到线上时，先在旧地址导出，再到线上家长页导入。

页面基于 [React](https://react.dev/learn) 和 [Vite](https://vite.dev/guide/)，没有引入业务数据库或收费API。必需图片由本地SVG绘制，无远程字体/图片加载。词库随应用打包，当前体积约130KB gzip；后续公网托管可按学科拆分加载。

真实浏览器检查使用Playwright CLI独立QA浏览器会话，不读写用户日常浏览器的学习数据。复查脚本在 `scripts/browser-check.js`，截图和测试备份在 `output/playwright/`。具体结果见 `实施与验收记录.md`。
