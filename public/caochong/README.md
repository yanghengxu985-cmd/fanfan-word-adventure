# 曹冲称象 · 河岸上的小实验

访问地址：https://yanghengxu985-cmd.github.io/fanfan-word-adventure/caochong/

## 使用

使用电脑浏览器或 iPad Safari 打开；iPad 推荐横屏。手机可直接竖屏使用专门的实验布局。可通过 Safari 的共享菜单添加到主屏幕。

1. 请大象上船，观察船下沉。
2. 在船身与水面相交处做记号。
3. 请大象下船，组合石头，直到黄色记号与水面重合。
4. 点选或拖动船上任意一块石头到左秤盘；等天平自动配平后，点击“记下来”。
5. 根据称量本计算总重量。桌面答对后自动回放；手机点“回看”在弹窗中比较两次同水位状态。

手机竖屏：主操作固定在底部；船与水线重新取景放大；称重时船在上、秤在下，石头可通过大卡片点选。称量本只展示最新记录，点“查看”打开全部记录。计算时收起空船，显示算式与输入框。声音、朗读、原理说明和重新开始位于顶部“更多”。输入框聚焦时操作栏根据可见视口调整位置。

支持取回石头、撤销组合、静音、朗读、随机重量挑战和减少动态效果的系统设置。音效由 Web Audio 在本地合成，在用户操作后启用，不需要下载音频。

## 文件与发布

`index.html` 是完整的独立课件，图像、样式、逻辑和声音均嵌入其中，下载后也能离线运行。文件中的 `lesson-engine`、`lesson-audio`、`lesson-ui` 三个脚本分别负责教学状态、轻音效和交互动画。

本目录放在 Vite 的 `public` 中，现有构建会将其复制到 `dist/caochong`；main 分支提交沿用仓库已有 GitHub Pages 自动部署。无需更改原应用入口、依赖或发布工作流。

## 验证

手机修复后完成 12 项教学与载重状态检查、5 项动画与回放生命周期检查、4 项音效检查，以及 4 项手机操作栏节点移动、表单关联和取景检查。操作栏检查使用轻量节点模型，取景检查覆盖 320/375/390/430/600px 宽度，均不代替真实浏览器验收。船体、标记和天平关键帧已做静态 SVG 视觉检查。脚本语法、静态 ID 和本地资源检查通过。真实手机及 iPad 的触控、全页布局、键盘避让和音量仍未实测。

船体和称量台均为教学示意：同一艘船、同样的水、相同水位记号对应相同载重。砝码由课件自动配平，图形尺寸不代表实物尺寸。
