## 映射和复现

`src/data/chineseImageDelivery.json` 以原有 `images/...` 路径作为键，记录主图、预览、尺寸、透明通道和体积。独立图格的键为原路径追加 `#frame=<index>`。交付文件名含内容哈希，内容变化后会生成新的网址。

`docs/CHINESE_IMAGE_DELIVERY_VERIFICATION.json` 记录来源/主图/预览 SHA-256、编码质量、透明通道比较及图格裁切坐标。

编码脚本是 `scripts/build-chinese-image-delivery.cjs`，需要 Sharp。可使用已有 Sharp 安装，或设置 `CODEX_SHARP_PATH` 为其模块目录。脚本从项目根目录运行：

```powershell
$env:CODEX_SHARP_PATH = '你的 Sharp 模块绝对路径'
node scripts/build-chinese-image-delivery.cjs sample
node scripts/build-chinese-image-delivery.cjs build
```

脚本以单线程和有限缓存运行，不更改源码画作。`build` 会逐个更新映射，以便网页预览读取已经生成的副本。生成结束后再执行项目构建与部署。

## 加载与验收

网页先显示当前情境的小预览，主图下载并解码后替换。加载提示位于原有画面内，不增加学习步骤或页面高度。失败或超过25秒时可重试；重试绕过已缓存的失败响应。相同图源在SVG裁切、放大镜与CSS精灵间共享下载，切换课程不会预载全书图片。自动分镜等待当前清晰图准备好再继续。

原图路径仍保留在课程数据与来源标注中，交付地址由统一映射选择。未加入缓存HTML的service worker，网站更新仍使用GitHub Pages的正常发布流程。
